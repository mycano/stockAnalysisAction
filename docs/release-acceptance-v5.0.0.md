## 评分与一票否决

每份报告使用 100 分评分卡：

| 维度 | 分值 |
|---|---:|
| 零工程视角泄漏 | 25 |
| 投资结论清晰 | 15 |
| 报告结构完整 | 15 |

| 投资者语言专业 | 10 |
| 风险与不确定性表达 | 5 |
| 行动条件可用 | 5 |

低于 85 分或出现以下任一情况即失败：内部对象或原始字段泄漏、章节缺失或重复、Deep 研究没有实质增强、基金持仓口径错误、异动把相关性写成因果、缺少人工投资者视角复核。

## 修复循环

第一轮业务审计没有直接作为发布结论，而是暴露并修复了以下问题：

1. 基金 Deep 报告把不足十只的披露样本重复写成“前十大持仓”，且压力测试与同类比较过于模板化。
2. 财报 Deep 的“多期趋势”与“会计质量”出现重复正文。
3. 异动报告曾复用同一段作为“可能原因”和“已确认原因”，并在 Quick 中夹带无关估值事实。
4. Lens 对抗报告曾让原始指标名穿透到正文，单 Lens 的证据与章节主题匹配不够准确。
5. 初版评分器没有把财报摘要、公告核验和异动验证信号识别为场景化结论与行动条件。

修复后重新生成并复核同一矩阵：

- 基金 Deep 展示真实披露持仓、阶段风格、管理归因、量化回撤压力与组合重叠检查。
- 个股 Deep 包含多期历史、三家同业、两种独立估值校验、量化三情景和反方审查。
- 异动报告明确区分公告事实、非因果假设、市场结构和后续证伪信号。
- Lens 报告将指标转换为自然语言名称、期间、单位及对应框架含义。
- 评分器按不同场景识别结论与行动条件，门槛仍保持 85 分。
